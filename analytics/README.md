# Offline assumption analytics

This directory is the reproducible, network-free analytics boundary for Test3. It uses base R only and never calls a hosted service. Run `Rscript analytics/r/run_all.R` from the repository root. Inputs are validated before use; outputs are deterministic CSV/JSON artifacts and remain candidates until an analyst approves a separate manual assumption in Test3.

The committed fixture and outputs are labeled **FICTIONAL SYNTHETIC MODEL — NOT FOR REAL UNDERWRITING**. They exist only to exercise the pipeline and cannot supply a controlling real-deal assumption.
