# Model artifact contract 1.0

Artifacts record model/version, target, immutable training snapshot hash, feature schema, training/validation windows, property and geographic coverage, sample size, coefficients and standard errors, metrics and residual diagnostics, limitations, exact source path and SHA-256, repository commit, R version, data status, and paths to the model card, validation results, and input schema. Test3 verifies the source hash before installation. Fictional artifacts are never eligible to control real underwriting.
