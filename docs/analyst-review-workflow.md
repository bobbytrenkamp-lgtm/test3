# Analyst review workflow

1. Import a licensed local panel and review row errors and coverage.
2. Run market-rent-growth intelligence with explicit geography context.
3. Inspect evidence, fallback, data window, sample size, limitations, and confidence components.
4. Select low/base/high, enter a custom value, or reject. Rationale and controlling source are mandatory.
5. Test3 creates a manual assumption and uses the existing append-only review chain. Recommendations never approve themselves.
6. Only the approved value can enter the Test2 export. The full recommendation and provenance remain a non-controlling sidecar.
