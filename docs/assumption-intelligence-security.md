# Assumption intelligence security

Processing is loopback/local. Imports are bounded to 16 MiB and 100,000 rows, decoded as UTF-8, formula-rejected, type-checked, FIPS-validated, and stored under generated names. Browser requests cannot select filesystem destinations or execute R/model code. SQLite foreign keys, tenant filters, append-only triggers, source hashes, audit hashes, and review hashes protect lineage. No API key or billable service is used.
