# Confidence methodology

Confidence is a documented weighted composite of sample size, completeness, freshness, geography match, property match, source quality, model validation, and model/benchmark agreement. Each component is retained with the run. Out-of-domain and broad-geography fallbacks cap the result. Confidence describes evidence fitness; it is not probability, investment advice, or approval.

Preferred history and sample requirements vary by assumption domain. Sparse domains remain usable only as low-confidence candidates, and unavailable metrics return an explicit unavailable run rather than a default. The data profile exposes per-metric periods, sources, geography coverage, property types, minima/maxima, staleness and an overall assumption-coverage ratio.
