# Model governance

Model artifacts are immutable, versioned, content-addressed records. Installation verifies the artifact and exact source-code SHA-256. Artifacts disclose training and validation windows, data snapshot, features, coverage, sample size, coefficients, standard errors, metrics, diagnostics, limitations, repository commit, R version, and supporting paths. Recommendations remain candidates and retain frozen evidence links. Fictional/synthetic artifacts are structurally testable but prohibited from contributing a real model estimate or controlling a real deal.
